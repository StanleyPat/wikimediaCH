# Wikimedia CH – WikiFacts Tinder 🃏

Interaktives Faktenquiz für Wikimedia CH, basierend auf dem Tinder-Prinzip (Swipe-Karten).

## Enthaltene Anwendungen

- **[wikifacts-tinder](wikifacts-tinder/)**: Reine Vanilla-Stack-Webanwendung (HTML5, CSS3, JavaScript) ohne externe Abhängigkeiten oder Build-Tools.

## Schnellstart

Einfach die Datei [wikifacts-tinder/index.html](wikifacts-tinder/index.html) per Doppelklick in einem beliebigen Browser öffnen oder via lokalem HTTP-Server starten:

```bash
cd wikifacts-tinder
python3 -m http.server 3000
```
Browser öffnen unter: [http://localhost:3000](http://localhost:3000)
